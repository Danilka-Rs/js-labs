## **Цель работы**

Цель данной лабораторной работы — знакомство с инструментами построения пользовательских интерфейсов web-сайтов: **HTML** и **CSS**.

В ходе выполнения работы необходимо было ознакомиться с реализацией простого калькулятора, создать HTML-разметку страницы, подключить CSS-стили и оформить интерфейс калькулятора в соответствии с выбранной темой.

## **Тема**

**Электронные услуги + кэшбэк.**

В рамках выбранной темы был разработан стилизованный **кэшбэк-калькулятор**. Интерфейс выполнен в виде терминального окна с неоновым оформлением. В проекте используются декоративные элементы, связанные с электронными услугами, денежными операциями и кэшбэком.

## **Сайт для вдохновения**

В качестве визуального вдохновения использовался стиль цифровых сервисов, терминалов и неоновых интерфейсов.

## **Описание проекта**

Проект представляет собой web-страницу с калькулятором, выполненную с использованием HTML, CSS и JavaScript.

На странице реализованы:

* блок с названием проекта **«Кэшбэк-Калькулятор»**;
* раскрывающийся блок с информацией об авторе;
* экран калькулятора для отображения введенных значений;
* кнопки цифр и математических операций;
* кнопка очистки;
* кнопка результата;
* ссылка на GitHub;
* футер с подписью автора и иконками, связанными с темой кэшбэка;
* выпадающий список для смены цветовой темы интерфейса.

## **Дополнительные задания**

### 1. Визуальный эффект нажатия кнопок

Для кнопок калькулятора был добавлен визуальный эффект при наведении и нажатии.
При наведении кнопка подсвечивается, а при нажатии немного смещается вниз, создавая ощущение физического нажатия.

```css
.k:active {
  transform: translateY(1px);
  box-shadow: inset 0 2px 8px rgba(0,0,0,0.4);
}
```

### 2. Адаптивная раскладка кнопок

Кнопки калькулятора размещены в удобной сеточной структуре с рядами.
Для отдельных кнопок, таких как `0` и `=`, увеличена ширина, чтобы интерфейс выглядел ближе к реальному калькулятору.

```css
.z { 
  width: 125px; 
}

.e {
  width: 125px;
  background: #1a2a25;
  border-color: #00ff9d;
  color: #fff;
}
```

### 3. Переключение цветовой темы

На странице реализован выпадающий список, позволяющий выбрать стиль интерфейса:

* `cyan`;
* `amber`;
* `lime`.

При выборе темы меняется цветовое оформление страницы, кнопок, экрана и декоративных элементов.

```html
<select id="theme">
  <option value="cyan">cyan</option>
  <option value="amber">amber</option>
  <option value="lime">lime</option>
</select>
```

```javascript
document.getElementById('theme').onchange = function() {
  document.body.className = this.value;
}
```
