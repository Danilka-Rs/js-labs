## **Цель**

Цель данной лабораторной работы — знакомство с инструментами построения пользовательских интерфейсов web-сайтов: HTML, CSS и JavaScript.

В ходе выполнения работы был реализован простой web-калькулятор с пользовательским интерфейсом, стилизацией и логикой обработки действий пользователя.

Тема проекта: **электронные услуги и кэшбэк**.

## **Описание интерфейса**

Интерфейс калькулятора выполнен в стиле ретро-терминала.

На странице расположены:

* заголовок **«Кэшбэк-Калькулятор»**;
* блок с информацией об авторе;
* экран вывода результата;
* кнопки цифр от `0` до `9`;
* кнопки арифметических операций;
* дополнительные кнопки действий;
* переключатель темы;
* ссылка на GitHub.

Экран калькулятора содержит мигающий курсор, что делает интерфейс похожим на терминал.

## **Функциональность калькулятора**

Калькулятор поддерживает следующие операции:

```text
сложение +
вычитание -
умножение *
деление /
процент %
квадратный корень √
возведение в квадрат x²
смена знака +/-
очистка C
удаление последнего символа ←
```

Для вычисления выражения используется JavaScript. После нажатия на кнопку `=` введённое выражение обрабатывается, а результат выводится на экран.

Если выражение некорректное или результат невозможно вычислить, на экране появляется сообщение:

```text
Ошибка
```

## **Дополнительные задания**

### 1. Ограничение количества символов на экране

В проекте реализована проверка длины выводимого значения. Если результат слишком длинный, он переводится в экспоненциальную форму.

```javascript
function updateDisplay(value) {
  if (value === '' || value === null || value === undefined) {
    value = '0';
  }

  let text = String(value);

  const maxLength = 12;

  if (!isNaN(text) && text.length > maxLength) {
    text = Number(text).toExponential(5);
  }

  outputElement.innerHTML = text + '<span class="cursor">_</span>';
}
```

### 2. Добавление десятичной точки с проверкой

В калькуляторе реализована проверка, которая не позволяет добавить две десятичные точки в одно число.

```javascript
if (digit === '.') {
  const lastPart = getLastNumberPart();
  if (lastPart.includes('.')) return;

  if (
    expression === '' ||
    /[+\-*/]$/.test(expression)
  ) {
    expression += '0.';
  } else {
    expression += '.';
  }
}
```

### 3. Проверка операторов

При вводе операторов выполняется проверка последнего символа выражения. Если выражение уже заканчивается оператором, новый оператор заменяет предыдущий.

```javascript
function addOperator(op) {
  resetIfError();

  if (expression === '') return;

  if (/[+\-*/]$/.test(expression)) {
    expression = expression.slice(0, -1) + op;
  } else {
    expression += op;
  }

  updateDisplay(expression);
}
```

### 4. Смена темы оформления

```javascript
themeSelect.onchange = function () {

```

Доступные темы:

```text

amber
lime
```
