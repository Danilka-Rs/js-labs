## **Цель**

Цель данной лабораторной работы — знакомство с Node.js, npm, подключением внешних библиотек и написанием простого веб-приложения на JavaScript.

В ходе выполнения работы было необходимо ознакомиться с реализацией простого интерфейса, выводом данных на страницу, работой с DOM-деревом, а также выполнить задание по своему варианту.

## **Тема**

**Кэшбэк-сервис.**

Приложение посвящено сервису возврата части денег за покупки в интернете. В проекте реализованы карточки cashback-предложений, которые пользователь может просматривать, открывать и получать дополнительную информацию через информеры.

## **Сайт для вдохновения**

В качестве сайта для вдохновения использовался cashback-сервис Backit.
https://backit.me
Основные идеи, взятые для реализации:

* верхний промо-блок;
* карточки предложений;
* акцент на выгоде и возврате денег;
* горизонтальные блоки с предложениями;
* светлый интерфейс с ярким акцентным цветом;
* слайдеры изображений.

## **Дополнительные задания**

1. Реализовать горизонтальное листание карточек.

В приложении создана горизонтальная лента карточек cashback-предложений. Для управления лентой используются кнопки:

```html
<button id="cards-prev" class="btn btn-outline-dark cards-nav-btn cards-nav-btn-left" type="button">
    ←
</button>

<div id="main-page" class="cards-scroll-container d-flex gap-4 overflow-auto pb-3"></div>

<button id="cards-next" class="btn btn-outline-dark cards-nav-btn cards-nav-btn-right" type="button">
    →
</button>
```

Логика листания реализована через метод `scrollBy`:

```javascript
prevBtn.addEventListener("click", () => {
    container.scrollBy({
        left: -380,
        behavior: "smooth"
    });
});

nextBtn.addEventListener("click", () => {
    container.scrollBy({
        left: 380,
        behavior: "smooth"
    });
});
```

2. Реализовать кнопку “Начать экономить”.

Кнопка находится в верхнем hero-блоке и плавно прокручивает страницу к разделу cashback-предложений.

```html
<button id="start-saving-btn" class="btn btn-dark btn-lg" type="button">
    Начать экономить
</button>
```

```javascript
addHeroButtonListener() {
    const button = document.getElementById("start-saving-btn");
    const offersSection = document.getElementById("offers-section");

    if (button && offersSection) {
        button.addEventListener("click", () => {
            offersSection.scrollIntoView({
                behavior: "smooth",
                block: "start"
            });
        });
    }
}
```

3. Добавить 3D-объект по теме проекта.

На странице карточки **“Кэшбэк на электронику”** добавлен 3D-объект — вращающаяся cashback-монета. Она символизирует возврат части денег пользователю.

HTML-разметка объекта:

```html
<div class="three-d-zone">
    <div class="coin3d">
        <div class="coin-face coin-front">₽</div>
        <div class="coin-face coin-back">%</div>
        <div class="coin-side"></div>
    </div>
</div>
```

CSS-анимация:

```css
.coin3d {
    width: 140px;
    height: 140px;
    margin: 0 auto;
    position: relative;
    transform-style: preserve-3d;
    animation: spinCoin 6s linear infinite;
}

@keyframes spinCoin {
    0% {
        transform: rotateY(0deg) rotateX(15deg);
    }
    100% {
        transform: rotateY(360deg) rotateX(15deg);
    }
}
```

4. Использовать Bootstrap Popover как информер.

В каждой карточке и на странице подробной информации есть кнопка-информер.

```html
<button
    class="btn btn-outline-secondary"
    type="button"
    data-bs-toggle="popover"
    data-bs-container="body"
    data-bs-placement="top"
    data-bs-title="Как это работает?"
    data-bs-content="Выбираешь магазин, активируешь кэшбэк, покупаешь и получаешь возврат части суммы.">
    Информер
</button>
```

Инициализация Popover выполняется вручную:

```javascript
new bootstrap.Popover(popoverElement, {
    container: "body",
    trigger: "click"
});
```

## **Описание приложения**

Разработанное приложение представляет собой простой cashback-сервис.

На главной странице пользователь видит:

* верхний промо-блок;
* кнопку “Начать экономить”;
* автоматический слайдер изображений;
* блок с преимуществами сервиса;
* горизонтальную ленту cashback-предложений.

В приложении реализовано 6 карточек:

1. **Кэшбэк на маркетплейсы**
2. **Кэшбэк на доставку продуктов**
3. **Кэшбэк на электронику**
4. **Кэшбэк на одежду**
5. **Кэшбэк на путешествия**
6. **Кэшбэк на онлайн-курсы**

Каждая карточка содержит:

* название предложения;
* краткое описание;
* процент кэшбэка;
* слайдер изображений;
* кнопку “Открыть”;
* кнопку “Информер”.

При нажатии на кнопку **“Открыть”** пользователь переходит на страницу подробной информации о выбранном cashback-предложении.

На странице подробной информации отображается:

* кнопка “Назад”;
* большой слайдер изображений;
* название предложения;
* подробное описание;
* процент кэшбэка;
* кнопка-информер;
* 3D-объект для карточки электроники.

## **Описание файлов**

### `index.html`

Файл содержит базовую HTML-разметку приложения.
В нём подключаются Bootstrap, файл стилей `styles.css` и основной JavaScript-файл `main.js`.

Главный элемент приложения:

```html
<div id="root"></div>
```

В этот элемент через JavaScript добавляется весь интерфейс приложения.

### `main.js`

Файл является точкой входа в приложение.

```javascript
import { MainPage } from "./pages/main/index.js";

const root = document.getElementById("root");

const mainPage = new MainPage(root);
mainPage.render();
```

В нём создаётся объект главной страницы и вызывается метод `render()`.

### `pages/main/index.js`

Файл содержит класс `MainPage`, который отвечает за главную страницу.

В нём реализованы:

* данные карточек;
* разметка главной страницы;
* hero-блок;
* блок преимуществ;
* горизонтальная лента карточек;
* кнопка “Начать экономить”;
* кнопки листания карточек;
* переход на страницу подробной информации.

### `components/cashback-card/index.js`

Файл содержит компонент `CashbackCardComponent`.

Компонент отвечает за одну карточку cashback-предложения.
В карточке отображаются:

* слайдер изображений;
* процент кэшбэка;
* название;
* описание;
* кнопка открытия;
* кнопка-информер.

### `pages/product/index.js`

Файл содержит класс `ProductPage`.

Он отвечает за страницу подробной информации о выбранном предложении.
Страница получает `id` выбранной карточки и по нему отображает нужные данные.

### `components/cashback-details/index.js`

Файл содержит компонент `CashbackDetailsComponent`.

Компонент отображает подробную карточку cashback-предложения.
Также именно здесь для карточки с электроникой выводится 3D-монета.

### `components/back-button/index.js`

Файл содержит компонент кнопки “Назад”.
При нажатии на кнопку пользователь возвращается на главную страницу.
